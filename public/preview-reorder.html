Curated Benchmark References

Industry standards for live physical reordering

5 Studied
1. Framer Motion Reorder
motion.dev

Uses continuous coordinate layout projection (`layoutId`). Sibling items dynamically calculate target bounding boxes and glide into new slots via critically tuned FLIP springs (`stiffness: 450, damping: 35`).

2. Pragmatic Drag-and-Drop / React Beautiful DnD
atlassian.design

Successor to React Beautiful DnD. Features instant bounding-box collision detection, live gap creation (sibling items slide apart by exact lifted height), and zero-lag edge auto-scrolling (`autoScroller`).

3. dnd-kit Sortable Presets
dndkit.com

`closestCenter` algorithm with offset translateY translations. Includes quadratic auto-scroll curves, touch sensors with 250-300ms delays, and smooth exit velocity preservation.

4. Apple iOS Reminders / Notes List Physics
Apple HIG

300ms hold with tactile haptic thud. Card lifts along Z-axis with scale 1.025 and ambient drop shadow. Critically damped springs (damping = 1.0, zero overshoot) displace adjacent rows smoothly.

5. SortableJS Native DOM Engine
sortablejs.github.io

Lightweight DOM FLIP reordering engine. Automatically manages ghost placeholders, in-place translateY recalculations, and container viewport edge auto-scrolling.
